# AmoreChat 💬

پیام‌رسان فارسی و self-hosted برای روزهای قطعی اینترنت بین‌الملل. روی یک سرور داخل ایران نصب می‌شود و **هیچ وابستگی به سرویس‌های خارجی ندارد**؛ تا وقتی شبکه داخلی وصل است، کار می‌کند.

## امکانات (نسخه ۰.۸)

- 📴 **حالت آفلاین** (پیام‌ها و عکس‌های اخیر بدون اتصال)، **صف ارسال** پیام و حالت خودکار **اینترنت ضعیف**
- 📊 **داشبورد سلامت سرور** با نمودار و **هشدار خودکار** به مدیران؛ بکاپ دوم روی دیسک دیگر (`BACKUP_MIRROR_DIR`)
- 🎨 ۱۰ تم، حالت روشن/تیره، اندازه متن و پس‌زمینه؛ 📁 پوشه‌های گفتگو و 📌 سنجاق
- 📱 **اپ اندروید** (APK روی همین سرور در `/app`): اعلان پیام و تماس وقتی برنامه بسته است **بدون نیاز به گوگل**، زنگ تماس تمام‌صفحه، اشتراک‌گذاری از برنامه‌های دیگر، بدون نیاز به نصب دستی گواهی در حالت آفلاین
- 📞 **تماس صوتی و تصویری** دونفره، 🎙 **کانال‌های صوتی** مثل Discord و **ویس‌چت گروهی** مثل تلگرام
- 🖥 **استریم** صفحه، پنجره، تب یا دوربین با کیفیت قابل انتخاب؛ حالت بی‌سیم (Push-to-talk)
- ⚙️ مدیر برای **هر کاربر** حجم فایل، سهمیه، اجازه تماس و استریم و سقف کیفیت را تعیین می‌کند

- 💬 چت خصوصی، گروه، کانال و «پیام‌های ذخیره‌شده»
- 📢 **کانال اطلاع‌رسانی اضطراری**: همه کاربران عضو آن هستند و پیام‌های آن به‌صورت بنر قرمز برای همه آنلاین‌ها نمایش داده می‌شود
- 🖼 ارسال عکس با انتخاب کیفیت (فشرده / اصلی) و فایل، با نوار پیشرفت آپلود؛ کشیدن و رها کردن و Paste
- 🎤 **پیام صوتی** با نمایش موج صدا، نشانگر سطح صدا هنگام ضبط و پخش با سرعت ۱.۵ و ۲ برابر (روی همه مرورگرها، شامل آیفون، پخش می‌شود)
- 🎬 **ویدیو با انتخاب کیفیت**: فرستنده بین 360p / 720p / اصلی انتخاب می‌کند؛ سرور نسخه‌های کم‌حجم و تصویر پیش‌نمایش می‌سازد و گیرنده هنگام پخش کیفیت را عوض می‌کند
- ↩️ پاسخ، ↪️ فوروارد، ✏️ ویرایش، 🗑 حذف، 📌 سنجاق، 😀 ری‌اکشن
- 🔍 **جستجوی متن کامل** در همه پیام‌ها یا داخل یک گفتگو (فارسی، با پیدا کردن کلمات ناقص) و پرش به پیام
- ⏱ **حذف خودکار پیام‌ها** (۱ ساعت تا ۱ ماه) برای هر گفتگو
- 🚩 **گزارش پیام** به مدیران و صف رسیدگی در پنل مدیریت
- 📉 **حالت کم‌مصرف** برای هر کاربر: عکس فقط با لمس بارگذاری می‌شود و ویدیو با کمترین کیفیت پخش می‌شود
- 🧹 سهمیه فضای هر کاربر و حذف خودکار فایل‌های قدیمی (برای دیسک‌های کوچک)
- ✓✓ وضعیت خوانده‌شدن، «در حال نوشتن…»، آنلاین / آخرین بازدید
- 🛡 **نقش‌ها و دسترسی‌های جزئی**
  - سطح سرور: مالک، ادمین (با دسترسی‌های قابل انتخاب: مدیریت کاربران، کدهای دعوت، تنظیمات، نظارت بر گروه‌ها، گزارش فعالیت، ارسال در کانال اطلاع‌رسانی)
  - سطح گروه/کانال: سازنده، ادمین (ویرایش، حذف پیام، حذف/مسدود کردن، بی‌صدا کردن، افزودن عضو، سنجاق، لینک دعوت، ارسال در کانال)
- 🔇 بی‌صدا کردن موقت، 🚫 مسدود کردن، 🐢 حالت آهسته، 🔒 قفل گروه
- 🎟 ثبت‌نام **آزاد / فقط با کد دعوت / بسته** (قابل تغییر توسط مالک)؛ کد دعوت با سقف استفاده و تاریخ انقضا
- 🔗 لینک دعوت گروه/کانال، گروه‌های عمومی و بخش «کاوش»
- 📊 پنل مدیریت: آمار سرور (رم، CPU، دیسک)، مدیریت کاربران، بازنشانی رمز، **گزارش فعالیت ادمین‌ها**
- 💾 **بکاپ خودکار روزانه** دیتابیس (۱۴ نسخه آخر نگه داشته می‌شود)
- 📱 **PWA**: روی گوشی و کامپیوتر نصب می‌شود؛ تم روشن/تیره خودکار؛ تاریخ شمسی؛ فونت وزیرمتن (بدون CDN)
- 🔐 رمزها با scrypt، کوکی httpOnly، محافظت CSRF، محدودیت تلاش ورود، فایل‌های آپلودی هرگز به‌صورت HTML اجرا نمی‌شوند
- 🔑 **ورود دومرحله‌ای** (TOTP) با کدهای بازیابی، **لیست دستگاه‌ها** و خروج از راه دور، خروج خودکار بقیه دستگاه‌ها بعد از تغییر رمز، قفل حساب بعد از تلاش‌های ناموفق، هشدار ورود جدید
- 🔕 بی‌صدا کردن هر گفتگو، **@منشن** (حتی در گفتگوی بی‌صدا خبر می‌دهد)، 👁 «دیده‌شده توسط»، 🖼 گالری رسانه‌ها و لینک‌ها
- 📶 نشانگر دائمی پینگ و کیفیت اتصال (صفحه اصلی، تماس و ویس‌چت)
- 🎙 ویس‌چت کانال مثل تلگرام (ادمین صحبت می‌کند، بقیه ✋ دست بلند می‌کنند)، 🔊 ولوم جداگانه هر نفر، 👥 اعضای مخفی کانال و ری‌اکشن ناشناس

## نصب روی سرور (Ubuntu 22.04 / 24.04)

### پیش‌نیازها
- سرور **داخل ایران** (حداقل ۲ هسته، ۲ گیگ رم؛ پیشنهاد: ۴ گیگ)
- یک دامنه که رکورد A آن به IP سرور اشاره کند
- این پورت‌ها هم روی سرور و هم در **فایروال پنل سرویس‌دهنده** باز باشند:

| پورت | کاربرد |
|---|---|
| `80/tcp`، `443/tcp`، `443/udp` | سایت |
| `7881/tcp` | تماس و ویس‌چت (وقتی UDP بسته است) |
| `7882/udp` | صدا و تصویر تماس و ویس‌چت |
| `3478/udp` | TURN برای کاربران پشت NAT |

اگر `ufw` فعال باشد، اسکریپت نصب خودش این پورت‌ها را باز می‌کند. IP عمومی سرور خودکار در `.env` (`PUBLIC_IP`) نوشته می‌شود؛ اگر سرور پشت NAT است آن را دستی اصلاح کنید.

> ⚠️ **DNS دامنه:** اگر DNS دامنه روی سرویس خارجی (مثل Cloudflare) باشد، در زمان قطعی دامنه باز نمی‌شود. DNS را روی یک سرویس داخلی (مثل ابر آروان) بگذارید.

### روش ۱: نصب یک‌خطی (پیشنهادی)
آخرین نسخه را با بسته آماده (بدون نیاز به Docker Hub) در پوشه `amorechat` نصب می‌کند:

```bash
curl -fsSL https://raw.githubusercontent.com/amor7/AmoreChat/main/deploy/get.sh | sudo bash
```

نصب یک **نسخه مشخص**:
```bash
curl -fsSL https://raw.githubusercontent.com/amor7/AmoreChat/main/deploy/get.sh | sudo bash -s -- v0.2.0
```

### روش ۲: سرور بدون دسترسی به گیت‌هاب

> 📴 **راهنمای کامل و قدم‌به‌قدم نصب آفلاین** (انتقال فایل‌ها، نصب Docker بدون اینترنت، نصب گواهی روی اندروید/آیفون/ویندوز/مک، آپدیت آفلاین و عیب‌یابی): **[docs/OFFLINE-INSTALL.md](docs/OFFLINE-INSTALL.md)**

از صفحه **Releases** فایل‌های `amorechat-source.tar.gz` و `amorechat-offline-amd64.tar.gz` را دانلود و به سرور منتقل کنید (مثلاً با `scp`)، سپس:

```bash
tar xzf amorechat-source.tar.gz && mv amorechat-offline-amd64.tar.gz amorechat/ && cd amorechat && sudo bash deploy/install.sh
```

اسکریپت دامنه را می‌پرسد، Docker را از مخازن اوبونتو نصب می‌کند و برنامه را بالا می‌آورد.

### راه‌اندازی اولیه
در پایان نصب یک **کد راه‌اندازی (SETUP CODE)** چاپ می‌شود. سایت را باز کنید و با این کد اولین حساب را بسازید؛ این حساب **مالک** سرور می‌شود. بعد از پنل مدیریت کد دعوت بسازید و برای بقیه بفرستید.

اگر کد را گم کردید:
```bash
docker compose logs app | grep "SETUP CODE"
```

## 🔒 گواهی SSL و حالت بدون اینترنت بین‌الملل

تماس، پیام صوتی، دوربین، نصب برنامه (PWA) و اعلان‌ها **فقط روی HTTPS** کار می‌کنند. حالت را با `TLS_MODE` در فایل `.env` انتخاب کنید و بعد `sudo docker compose up -d` بزنید:

| `TLS_MODE` | کاربرد | اینترنت بین‌الملل لازم است؟ |
|---|---|---|
| `auto` (پیش‌فرض) | Let's Encrypt؛ برای زمان عادی | بله، هنگام صدور و هر تمدید (~۹۰ روز) |
| `internal` | **گواهی خود سرور**؛ نصب آفلاین، قطعی طولانی، یا فقط IP (مثلاً `DOMAIN=185.1.2.3`) | **خیر** |
| `custom` | گواهی خریداری‌شده: `certs/cert.pem` و `certs/key.pem` | فقط هنگام خرید |

در حالت `internal` هر دستگاه **یک بار** گواهی سرور را نصب می‌کند: صفحه `http://آدرس-سرور/ca` را باز کنید، فایل را دانلود کنید و طبق راهنمای همان صفحه (اندروید، آیفون، ویندوز، مک) نصب کنید. بهتر است این کار قبل از قطعی انجام شود.

> امنیت فعلی: ارتباط کاربر تا سرور رمزنگاری می‌شود (TLS) و رمزها با scrypt ذخیره می‌شوند، ولی پیام‌ها روی سرور **رمزنگاری سرتاسری (E2E) ندارند**؛ یعنی کسی که به سرور دسترسی کامل دارد می‌تواند آن‌ها را بخواند.

## ✅ چک‌لیست قبل از قطعی

- [ ] سرور داخل ایران است و DNS دامنه روی سرویس داخلی است
- [ ] برنامه نصب و تست شده و کاربران حساب ساخته‌اند و **PWA را روی گوشی نصب کرده‌اند**
- [ ] گواهی SSL تازه است (Caddy خودکار تمدید می‌کند؛ اعتبار حدود ۹۰ روز). برای قطعی‌های طولانی می‌توانید گواهی یک‌ساله بخرید، `cert.pem` و `key.pem` را در پوشه `certs/` بگذارید و خط `tls` را در فایل `Caddyfile` (پوشه اصلی برنامه) فعال کنید
- [ ] IP سرور را هم به کاربران بدهید (برای روزی که DNS مشکل داشت)
- [ ] فضای دیسک کافی است (پنل مدیریت ← آمار)

## 💾 بکاپ و بازیابی

- بکاپ دیتابیس هر روز خودکار در `data/backups/` ساخته می‌شود.
- **از پنل مدیریت ← پشتیبان** (فقط مدیر اصلی) می‌توانید بدون دسترسی به سرور دانلود کنید: فقط دیتابیس، **بکاپ کامل** (فایل `.tar` شامل `amorechat.db` و پوشه `uploads/`)، یا یکی از نسخه‌های روزانه.
- بکاپ دستی: `docker compose exec app node server/src/backup-cli.js`
- فایل‌های آپلودی در `data/uploads/` هستند. برای بکاپ کامل، کل پوشه `data/` را کپی کنید.
- بازیابی: برنامه را متوقف کنید (`docker compose down`)، فایل بکاپ را جای `data/amorechat.db` بگذارید (و `amorechat.db-wal` را پاک کنید) و دوباره `docker compose up -d`.
- بازیابی بکاپ کامل: `tar -xf amorechat-full-….tar -C data/` (فایل دیتابیس و پوشه uploads سر جایشان قرار می‌گیرند)، بعد مثل بالا.
- اگر کاربری گوشی ورود دومرحله‌ای را گم کرد و کد بازیابی ندارد: پنل مدیریت ← کاربران ← «خاموش کردن ورود دومرحله‌ای».

## 📱 اپ اندروید

- کاربران از `https://<سرور>/app` (در حالت آفلاین: `http://<سرور>/app`) فایل APK را دانلود و نصب می‌کنند و آدرس سرور را وارد می‌کنند.
- در اپ می‌توانید **چند سرور AmoreChat** اضافه کنید (مثلاً سرور خودتان و سرور دوستان)؛ روی همه وارد می‌مانید، پیام و تماس همه می‌آید و از منوی بالای لیست گفتگوها جابه‌جا می‌شوید.
- اعلان‌ها از یک اتصال مستقیم به همین سرور می‌آیند، نه از گوگل؛ پس در قطعی اینترنت بین‌الملل هم کار می‌کنند. در پروفایل قابل خاموش کردن است.
- APK با یک کلید ثابت امضا می‌شود (در GitHub Secrets: `ANDROID_KEYSTORE_B64` و `ANDROID_KEYSTORE_PASSWORD`). **از این کلید نسخه پشتیبان نگه دارید**؛ بدون آن، نسخه‌های بعدی روی اپ نصب‌شده آپدیت نمی‌شوند.
- کد اپ در پوشه `android/` است و در GitHub Actions ساخته و روی شبیه‌ساز اندروید تست می‌شود.

## ⬆️ به‌روزرسانی

```bash
sudo amorechat-update            # آخرین نسخه
sudo amorechat-update v0.2.0     # یک نسخه مشخص (بالاتر یا پایین‌تر)
```

قبل از به‌روزرسانی خودکار بکاپ گرفته می‌شود. `data/`، `.env`، `Caddyfile` و `certs/` دست نمی‌خورند و دیتابیس خودکار ارتقا پیدا می‌کند. برگشت به نسخه قدیمی‌تر قبل از اجرا تأیید می‌گیرد.

نصب‌های قبل از v0.2.1 هنوز دستور `amorechat-update` را ندارند؛ یک بار **داخل پوشه برنامه** بزنید:
```bash
curl -fsSL https://raw.githubusercontent.com/amor7/AmoreChat/main/deploy/update.sh | sudo AMORECHAT_DIR="$PWD" bash
```

بدون دسترسی سرور به گیت‌هاب: دو فایل نسخه جدید را به پوشه برنامه منتقل کنید و بزنید:
```bash
tar xzf amorechat-source.tar.gz --strip-components=1 && sudo bash deploy/install.sh
```

## 🧑‍💻 توسعه

نیازمندی: Node.js 24 یا جدیدتر.

```bash
npm install
npm run dev:server     # API روی پورت 3000
npm run dev:web        # رابط کاربری روی پورت 5173 (با پراکسی به API)
```

- `server/` — Fastify + Socket.IO + SQLite داخلی Node (`node:sqlite`)
- `web/` — React + Vite + PWA
- تست: `node server/test/smoke.mjs http://localhost:3000 <SETUP_CODE>` روی یک دیتابیس خالی

ساختن بسته آفلاین: کافی است یک تگ بزنید (`git tag v0.1.0 && git push --tags`) تا GitHub Actions بسته را بسازد و در Releases بگذارد.
