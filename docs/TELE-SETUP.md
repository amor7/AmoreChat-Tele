# راه‌اندازی Tele (تلگرام از طریق VPN سرور)

راهنمای کامل قدم‌به‌قدم (با نصب آفلاین): **[OFFLINE-INSTALL.md ← بخش ۱۰](OFFLINE-INSTALL.md#۱۰-راهاندازی-تلگرام-tele)**. این صفحه خلاصه و مرجع است.

## چه چیزهایی داخل ایمیج هست
- **TDLib** (`tdl` + `prebuilt-tdlib`) برای ورود و پیام‌رسانی تلگرام
- **sing-box** (نسخه 1.14.x، با checksum بررسی‌شده) برای تونلی که فقط ترافیک تلگرام را به پروکسی می‌برد

روی سرور چیزی جدا نصب نمی‌کنید. برای استفاده از sing-box دیگری: `SING_BOX_PATH` در `.env` یا فایل `data/bin/sing-box`.

## تنظیمات `.env`

| متغیر | توضیح |
|---|---|
| `TELEGRAM_API_ID`، `TELEGRAM_API_HASH` | از https://my.telegram.org (لازم) |
| `TELE_IDLE_MINUTES` | بعد از چند دقیقه بی‌استفاده بودن، اتصال تلگرام بسته شود (پیش‌فرض ۱۰) |
| `TELE_SOCKS_PORT` | پورت محلی تونل داخل کانتینر (پیش‌فرض 17890) |
| `SING_BOX_PATH` | مسیر sing-box دیگر (اختیاری) |

بعد از تغییر: `sudo docker compose up -d`

## فرمت‌های پروکسی (پنل مدیریت ← Tele / VPN)

دو راه: **فرم دستی** برای هر نوع (یوزر/پسورد SOCKS و HTTP اختیاری) یا **چسباندن** لینک/کانفیگ:

| نوع | ورودی |
|---|---|
| WireGuard | کل فایل `.conf` همان‌طور که هست (PresharedKey، MTU، چند Peer)؛ چند فایل پشت سر هم = چند پروکسی |
| VLESS | `vless://…` شامل Reality (`pbk`/`sid`/`fp`)، `ws`، `grpc`، `httpupgrade` |
| VMess | `vmess://…` (با tls و ws/grpc) |
| Trojan | `trojan://…` |
| Shadowsocks | `ss://…` (SIP002 و قدیمی، با plugin) |
| Hysteria2 | `hy2://…` یا `hysteria2://…` (با obfs) |
| TUIC | `tuic://…` |
| SOCKS5 | `socks5://USER:PASS@IP:PORT`، بدون رمز `socks5://IP:PORT`؛ قالب فروشنده‌ها `IP:PORT:USER:PASS` و `socks5://IP:PORT@USER:PASS` هم خودکار مرتب می‌شود |
| SOCKS4 / 4a | `socks4://IP:PORT`، `socks4a://IP:PORT` (بدون پسورد) |
| HTTP / HTTPS | `http://USER:PASS@IP:PORT`، `https://…` (CONNECT) |
| اشتراک | متن base64 لینک اشتراک |
| JSON | یک outbound/endpoint sing-box یا کل فایل کانفیگ |

برای امنیت، outboundهایی مثل `direct`، `selector`، `urltest` یا `detour` پذیرفته نمی‌شوند؛ تلگرام فقط از پروکسی وصل می‌شود.

## تست و انتخاب خودکار
- **تست** هر پروکسی: اتصال واقعی از طریق همان پروکسی به دیتاسنتر تلگرام و اندازه‌گیری تأخیر.
- **تست خودکار**: روشن/خاموش و فاصله به دقیقه؛ بعد از هر دور بهترین پروکسی سالم طبق سیاست انتخاب و در صورت خرابی پروکسی فعلی، تونل خودکار عوض می‌شود.
- سیاست‌ها: اولویت، بهترین تأخیر، تصادفی، دستی.

## کاربر
منو ← **تلگرام** ← شماره ← کد ← (رمز دومرحله‌ای) ← دکمه **+** برای افزودن گفتگوها. ریپلای با دوبار کلیک یا دکمه پاسخ. عکس فقط برای کاربرانی که مدیر اجازه داده.

## اصول امنیتی
- فقط ترافیک Tele از پروکسی می‌گذرد؛ چت داخلی روی شبکه سرور می‌ماند.
- بدون پروکسی سالم، تلگرام **مستقیم وصل نمی‌شود** (fail-closed)؛ TDLib هم هیچ پروکسی دیگری جز تونل ندارد.
- کانفیگ پروکسی‌ها، کلیدها و نشست‌های تلگرام فقط روی سرور و با دسترسی محدود (۰۶۰۰/۰۷۰۰) ذخیره می‌شوند و به کاربران نمایش داده نمی‌شوند؛ کاربران عادی آدرس سرور پروکسی یا خطاهای تونل را نمی‌بینند.
- ورود به تلگرام محدودیت تعداد درخواست دارد؛ تغییرات پروکسی و دسترسی‌ها در «گزارش فعالیت» ثبت می‌شود.
